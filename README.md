# DAC Documentation

This repository contains the official documentation for the **DAC (Dual Assets Quantum Chain)** project, built using [VitePress](https://vitepress.dev/).

## Project Structure

The project is built on VitePress and Tailwind CSS. The documentation content is located in the `docs/` folder, while the configuration and custom theme (based on the "DAC Quantum 2026" visual model) are found in `.vitepress/`.

```text
.
├── .vitepress/          # VitePress configuration and theme (CSS, components)
├── docs/                # Documentation content in Markdown
├── package.json         # Dependencies and npm scripts
├── tailwind.config.js   # Tailwind CSS configuration
└── dac-docs.conf        # Example Apache2 configuration for deployment
```

## Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher)

## Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:dacblockchain/documentation.git
   cd documentation
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

## Development Commands

The project includes the following npm scripts for development and deployment:

### Start local development server
Starts a local server with Hot Module Replacement (HMR) to view changes in real time:
```bash
npm run docs:dev
```
The site will be accessible at `http://localhost:5173` (or another port indicated in the terminal).

### Build for production
Generates the static files for the site release:
```bash
npm run docs:build
```
The compiled files will be saved in the `.vitepress/dist` directory.

### Preview local build
Starts a server to test the production build locally:
```bash
npm run docs:preview
```

## Style and Design System
The theme follows the "DAC Quantum 2026" stylistic guidelines, implementing a flat design (no border-radius or box-shadow), unified brand colors, and standard typography. Global CSS is managed with Tailwind and imported into the theme file `.vitepress/theme/style.css`. The project also includes a cookie-consent banner; legal or regulatory compliance requires separate review.

## Deployment
You can use the included `dac-docs.conf` file as a starting point to configure your web server (e.g., Apache2) to serve the static files generated by the build.
